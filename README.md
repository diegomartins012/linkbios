# Link na Bio — Diego Martins

Página estática (HTML + CSS + JS puro, sem instalar nada).

## O que editar (tudo comentado)
1. **`config.js`** → seus links (WhatsApp, Behance, Instagram, site, e-mail) e o caminho da foto.
2. **`assets/foto.jpg`** → salve sua foto com esse nome (ou mude o nome em `config.js`).
3. **`index.html`** → textos (títulos, descrições). Procure os comentários `✏️`, `🖼️` e `➕`.
4. **`style.css`** → cores no topo do arquivo (`:root`).

## Testar
Abra o `index.html` no navegador (ou "Live Server" no Antigravity).

## Publicar e colocar na bio
Suba a pasta inteira em Netlify Drop, Vercel, GitHub Pages ou Cloudflare Pages
e cole o link gerado no Instagram: Editar perfil → Links.
